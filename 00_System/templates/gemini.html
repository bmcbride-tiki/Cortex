Python Flow-Through Script Integration Manual

Workbrain scripts can call this Gemini bridge directly via its JSON-payload CLI contract. Authentication reuses your machine's signed-in Gemini session (shared SSO) -- run the init action once, then every later call reuses those saved cookies headlessly:

python gemini_bridge.py "{\"action\": \"init\"}"
python gemini_bridge.py "{\"action\": \"ask\", \"prompt\": \"Summarize this text...\"}"
python gemini_bridge.py "{\"action\": \"search\", \"prompt\": \"What changed in the latest Red Seal standard?\"}"
python gemini_bridge.py "{\"action\": \"generate_image\", \"prompt\": \"A friendly robot mascot\"}"
