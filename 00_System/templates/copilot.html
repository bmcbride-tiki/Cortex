Python Flow-Through Script Integration Manual

Workbrain scripts can call this Copilot bridge directly via its JSON-payload CLI contract. Authentication reuses your machine's signed-in Edge session (enterprise SSO) -- run the init action once, then every later call reuses that saved session headlessly:

python copilot_bridge.py "{\"action\": \"init\"}"
python copilot_bridge.py "{\"action\": \"ask\", \"prompt\": \"Summarize this text...\"}"
python copilot_bridge.py "{\"action\": \"generate_image\", \"prompt\": \"A friendly robot mascot\"}"
python copilot_bridge.py "{\"action\": \"list_agents\"}"
python copilot_bridge.py "{\"action\": \"ask_agent\", \"agent\": \"Hal-9000\", \"prompt\": \"What's on my plate today?\"}"
